# Array Visualiser

A really simple array visualizser built in Java I made for fun. Uses the javax.swing library.

## Features

It's a small project, but here's the available features anyways:
- Colours
- Resizing the window

Available sorting algorithms:
- Bubble Sort
- Insertion Sort
- Gnome Sort
- Selection Sort
- Shell Sort
- Merge Sort
- Heap Sort
- Quick Sort
- Radix Sort (Least Significant Digit)
